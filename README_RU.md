# MIN RP — стартовый сервер

Это стартовый HTTP API-прототип на Python для самостоятельного RP-проекта. Это **не** сервер оригинальной Black Russia и пока не 3D-игра.

## Развёртывание на Render через Android

1. Создай репозиторий на GitHub и загрузи в него все файлы из архива.
2. В Render выбери **New + → Web Service** и подключи репозиторий.
3. Build Command: `pip install -r requirements.txt`
4. Start Command: `gunicorn app:app --bind 0.0.0.0:$PORT`
5. После развёртывания открой адрес сервиса. Ответ должен содержать `MIN RP` и `online`.

## API
- `GET /` — информация о сервере
- `GET /health` — проверка работы
- `POST /register` JSON: `{"username":"player1","password":"пароль-не-короче-8"}`
- `POST /login` JSON: `{"username":"player1","password":"..."}`
- `GET /me` — нужен заголовок `Authorization: Bearer <token>`
- `GET /players` — список зарегистрированных игроков
- `POST /work` — нужна авторизация; начисляет 250 игровых долларов
- `POST /logout` — завершает текущую сессию

## Важно
На бесплатном хостинге локальная SQLite-база может сбрасываться при перезапуске или новом развёртывании. Для реальных аккаунтов подключи PostgreSQL и добавь защиту от злоупотреблений. Не используй этот прототип для настоящих платежей или реальных паролей.
